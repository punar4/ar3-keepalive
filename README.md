# ar3-keepalive

A scheduled GitHub Actions workflow that keeps the free-tier [AR3](https://github.com/punar4/ar3) demos awake during hackathon judging:

- the UPI and card demo on Streamlit (https://ar3-payments.streamlit.app), every 4 hours
- the PayPal demo on Render (https://ar3-paypal.onrender.com), every 10 minutes

It can be switched off after judging ends (late December 2026).
